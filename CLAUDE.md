# German Vocabulary Analysis & Study Platform

This file provides architectural context, tool workflows, and synchronization guidelines for Claude (the primary repository editor) and Antigravity (pair programming assistant).

---

## 1. System Architecture & Components

The repository is structured into two main workspaces:
* **`vocab_bank/`**: The data generation, source aggregation, audio indexing, and verification engine.
* **`STUDY_HERE/`**: The user-facing study environment (contains interactive flashcard app, Anki-ready CSVs, and study assets).

### Key Directories
* `vocab_bank/bank_final/`: Master CSV banks (`vocabulary_bank.csv`, `b2_vocabulary_bank.csv`, `phrase_bank.csv`, `redemittel_bank.csv`).
* `vocab_bank/bank_final/audio/`: Master native pronunciation audio files (9,265+ files, ~328 MB, format: `.wav`, `.ogg`, `.mp3`).
* `vocab_bank/work/audio_manifest.json`: Single source of truth for audio mappings (`word`, `file`, `source`, `speaker`, `error`).
* `vocab_bank/bank_final/German_Vault/`: Complete Obsidian Vault with Johnny Decimal structure, frontmatter YAML, audio embeds, and video links.
* `STUDY_HERE/German_Study.html`: Standalone, interactive local web application for active recall study and search.
* `STUDY_HERE/Anki_Ready_Vocabulary.csv`: Pre-formatted Anki import file with native `[sound:file.ext]` tags and video links.

## 2. Audio Pipeline & Critical Fixes

Audio is downloaded and verified by `vocab_bank/work/download_audio.py` using a two-tier strategy:
1. **Tier 1 (Lingua Libre SPARQL Endpoint)**: Fetches verified German native recordings from the Wikimedia/Lingua Libre SPARQL service.
2. **Tier 2 (Wikimedia Commons Fallback)**: Checks Wiktionary standard audio files (`File:De-{word}.ogg`, `File:De-{word}.wav`).

### Critical Bug Fixes Implemented:
* **Lingua Libre SPARQL Property Bug**:
  * *Original*: Queried `prop:P5 ?word` (an internal entity identifier) and `prop:P6 ?speaker` (a timestamp), returning 0 hits.
  * *Fixed*: Corrected to `prop:P7 ?word` (the transcription string) and `prop:P2 ?speaker` (the speaker entity), recovering thousands of native recordings.
* **Wikimedia Rate-Limiting (HTTP 429)**:
  * Strict Wikimedia API policy requires an informative `User-Agent` with contact information (`MedicaGermanStudy/1.0 (https://github.com/...; contact: student)`) and a polite sleep delay (`--sleep 0.8`) between downloads to prevent IP bans.
* **Windows Terminal `cp1252` Encoding Crash**:
  * Speaker output printing wrapped in `try / except UnicodeEncodeError` to support non-ASCII speaker handles cleanly on Windows environments.
* **Case-Insensitive Audio Stem Resolution**:
  * `make_vault.py` was updated to check stem matching case-insensitively (`Fett.wav` vs `fett.wav`) preventing false-positive broken links in the vault integrity checker.

## 3. Obsidian Vault Architecture & Audio Integration

* **Note-Level Audio Embedding**:
  * Audio is **not** kept in an isolated separate vocabulary category. Each word note directly embeds its own pronunciation:
    ```markdown
    # der Apfel

    ![[Apfel.wav]]

    [▶️ YouGlish](https://youglish.com/pronounce/Apfel/german) · [🎬 PlayPhrase](https://www.playphrase.me/#/search?q=Apfel&language=de)
    ```
  * In the note frontmatter, `audio: "Apfel.wav"` is preserved.
  * When opened in Obsidian Reading Mode, the note displays an interactive native audio player right under the title.
* **1-Click Video Learning**:
  * `[▶️ YouGlish]`: Direct query to authentic YouTube clips showing native German speakers using the exact lemma in context.
  * `[🎬 PlayPhrase]`: Direct query to German movie and TV show dialogue snippets for cinematic pronunciation.

## 4. Anki Import Specifications

* **File**: `STUDY_HERE/Anki_Ready_Vocabulary.csv` (generated by `vocab_bank/work/export_anki.py`)
* **Audio Field**: Formatted using standard Anki audio syntax: `[sound:Apfel.wav]`
* **Columns Exported**:
  1. `Word`
  2. `Audio` (`[sound:file.ext]`)
  3. `Part of Speech`
  4. `Article`
  5. `Plural`
  6. `Forms` (`pres_3sg`, `preterite`, `perfect`)
  7. `English Meaning`
  8. `German Example`
  9. `English Example`
  10. `Collocations`
  11. `Level`
  12. `Topic`
  13. `YouGlish Link`
  14. `PlayPhrase Link`

## 5. Routine Build & Sync Commands

To rebuild outputs after updating word banks:
```bash
cd vocab_bank

# 1. Download audio for missing words
python work/download_audio.py --level <A1|A2|B1|B2|C1|all> --sleep 0.8

# 2. Rebuild the Obsidian vault
python work/make_vault.py

# 3. Rebuild the interactive study web app
python work/make_study_app.py

# 4. Rebuild the Anki CSV export
python work/export_anki.py
```
