# German bank build (Medica)

This folder holds a long-running build of three German banks: vocabulary, phrases, Redemittel.

- Full task and rules: `CLAUDE_CODE_PROMPT.txt` (read it at the start of every session). Data dictionary and writing rules: `input\README_input.txt`.
- Resume rule: if `bank_final\progress.md` exists, read it first and continue with the next unfinished step. Never restart and never redo finished blocks.
- Hard rules: `input\` is read-only. Write only to `bank_final\` and `work\`. Never delete files. Never touch `anki\` or any other folder. CSV files are UTF-8 with BOM (`encoding="utf-8-sig"`). Never print whole data files. German must be flawless; unsure facts get a flag in the `check` column. Do not ask questions.
- Tools: `work\bank_tools.py` (status, next, apply, validate, export), `work\b2.py` and `work\b2chk.py` (B2 bank), `work\make_vault.py` (Obsidian vault in `bank_final\German_Vault`). `work\make_study_app.py` (flashcard page `..\STUDY_HERE\German_Study.html`). `work\make_level_workbook.py` (Excel with one sheet per level). `work\download_audio.py` (native German audio from Lingua Libre / Wikimedia Commons into `bank_final\audio`, manifest `work\audio_manifest.json`; `make_vault.py` and `make_study_app.py` use the files when present; needs internet access to lingualibre.org and commons.wikimedia.org). `work\make_word_lists.py` (clean word lists, Anki JSON and vault zip in `..\WORD_LISTS`). Source lists and PDFs live in `..\source_lists`. See `README.md` for the file map.
- Clean-up on 2026-10-14, approved by the owner: old working scripts (append_batches*.py, trackers), n-gram batch files, duplicate analysis copies, backups and pip wheels were removed from the working tree (they remain in the git history). Kept: all vocabulary data (now in `..\source_lists`), all PDFs, the banks, the tools. Do not recreate the old files.
